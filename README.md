# Contact Us Page

A simple contact page built with plain **HTML and CSS**. It has a contact form on the left and the business location with a map on the right.

## What's on the page

- A contact form with Name, Email, Subject and Message fields and a Send button
- Input boxes that get a blue border when you click inside them
- A Send button that turns darker blue when you hover over it
- A location box with address, phone, email and a map image
- On small screens (phones), the two sides stack one below the other

## What I practised

- Building a layout with Flexbox
- Styling forms (labels, inputs, textarea, button)
- Hover and focus effects
- Using a media query to make the page work on phones

## How to run

Open `index.html` in your browser, or use the **Live Server** extension in VS Code.
